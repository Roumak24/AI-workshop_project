# ✦ Project – AI SaaS Landing Page

A modern and responsive landing page built using **HTML5 and Tailwind CSS**. This project focuses on creating a clean SaaS-style navigation interface with a sticky navbar, modern typography, and a prominent call-to-action button.

## 🚀 Features

- **Sticky Navigation Bar:** Navigation stays at the top while scrolling.
- **Project Branding:** Custom logo text – ✦ Project.
- **Navigation Links:**
  - Product
  - Solutions
  - Resources
  - Pricing
  - Log in
- **Call-to-Action Button:** Get AI Free.
- **Responsive Design:** Built using Tailwind CSS utility classes and responsive breakpoints.
- **Modern UI:** Clean layout with a minimal SaaS-inspired design.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS (CDN)
- CSS3

## ⚙️ Getting Started

Follow these steps to run the project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd project
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in VS Code.

## 🎨 Tailwind CSS Setup

This project uses the Tailwind CSS CDN directly inside the HTML file.

```html
<script src="https://cdn.tailwindcss.com"></script>
```

No additional installation or build configuration is required.

## 📱 Responsiveness

The layout uses Tailwind CSS responsive utility classes to adapt to different screen sizes.
